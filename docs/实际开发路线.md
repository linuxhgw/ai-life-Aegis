# 2. MCP 怎么写？怎么接入？

你可以把 MCP 理解成：

> **给 AI 用的 API。**

普通 API 是给前端调用的：

```text
前端 → 后端 API → 数据库
```

MCP 是给 agent 调用的：

```text
Hermes → MCP Tool → 你的程序 → SQLite / Windows / 微信
```

MCP 官方 Python SDK 说明里也说，MCP 可以让应用以标准化方式给 LLM 暴露工具、资源和提示；Tools 类似 POST 接口，用来执行有副作用的动作，比如写数据库、发通知。([GitHub][3])

## 第三步：写 MCP Server

先建 `mcp_server.py`：

```python
import sqlite3
from datetime import datetime
from mcp.server.fastmcp import FastMCP

DB_PATH = "aegis.db"

mcp = FastMCP("Aegis")


def get_conn():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    return conn


def init_db():
    conn = get_conn()
    conn.executescript("""
    CREATE TABLE IF NOT EXISTS tasks (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT NOT NULL,
      scheduled_time TEXT,
      required_feedback TEXT,
      status TEXT DEFAULT 'pending',
      created_at TEXT DEFAULT CURRENT_TIMESTAMP,
      completed_at TEXT
    );

    CREATE TABLE IF NOT EXISTS feedbacks (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      task_id INTEGER NOT NULL,
      feedback_type TEXT NOT NULL,
      content TEXT,
      created_at TEXT DEFAULT CURRENT_TIMESTAMP,
      FOREIGN KEY(task_id) REFERENCES tasks(id)
    );
    """)
    conn.commit()
    conn.close()


@mcp.tool()
def create_task(title: str, scheduled_time: str, required_feedback: str = "text") -> dict:
    """
    创建一个 Aegis 计划任务。
    scheduled_time 建议使用 ISO 格式，例如 2026-05-24T20:00:00+08:00。
    required_feedback 可选：text, photo, checkin, location, choice。
    """
    conn = get_conn()
    cur = conn.execute(
        """
        INSERT INTO tasks (title, scheduled_time, required_feedback, status)
        VALUES (?, ?, ?, 'pending')
        """,
        (title, scheduled_time, required_feedback),
    )
    conn.commit()
    task_id = cur.lastrowid
    conn.close()

    return {
        "ok": True,
        "task_id": task_id,
        "title": title,
        "scheduled_time": scheduled_time,
        "required_feedback": required_feedback,
        "status": "pending",
    }


@mcp.tool()
def list_tasks(date: str = "") -> dict:
    """
    查询任务。
    date 可传 YYYY-MM-DD；不传则返回所有未完成任务。
    """
    conn = get_conn()

    if date:
        rows = conn.execute(
            """
            SELECT id, title, scheduled_time, required_feedback, status, created_at, completed_at
            FROM tasks
            WHERE substr(scheduled_time, 1, 10) = ?
            ORDER BY scheduled_time ASC
            """,
            (date,),
        ).fetchall()
    else:
        rows = conn.execute(
            """
            SELECT id, title, scheduled_time, required_feedback, status, created_at, completed_at
            FROM tasks
            WHERE status != 'completed'
            ORDER BY scheduled_time ASC
            """
        ).fetchall()

    conn.close()

    return {
        "ok": True,
        "tasks": [dict(row) for row in rows],
    }


@mcp.tool()
def complete_task(task_id: int) -> dict:
    """
    将任务标记为完成。
    """
    now = datetime.now().isoformat(timespec="seconds")

    conn = get_conn()
    cur = conn.execute(
        """
        UPDATE tasks
        SET status = 'completed', completed_at = ?
        WHERE id = ?
        """,
        (now, task_id),
    )
    conn.commit()
    changed = cur.rowcount
    conn.close()

    return {
        "ok": changed > 0,
        "task_id": task_id,
        "status": "completed" if changed > 0 else "not_found",
        "completed_at": now if changed > 0 else None,
    }


@mcp.tool()
def record_feedback(task_id: int, feedback_type: str, content: str) -> dict:
    """
    记录用户对某个任务的反馈。
    """
    conn = get_conn()
    cur = conn.execute(
        """
        INSERT INTO feedbacks (task_id, feedback_type, content)
        VALUES (?, ?, ?)
        """,
        (task_id, feedback_type, content),
    )
    conn.commit()
    feedback_id = cur.lastrowid
    conn.close()

    return {
        "ok": True,
        "feedback_id": feedback_id,
        "task_id": task_id,
        "feedback_type": feedback_type,
        "content": content,
    }


if __name__ == "__main__":
    init_db()
    mcp.run()
```

这就是你的第一个 Aegis MCP Server。

具体字段名要看你安装的 Hermes 版本。官方文档学习路径里明确有 MCP 入口，但不同版本的配置文件命名可能会变化。([GitHub][2])

settings

那就先走 **Hermes Plugin / Built-in Tool** 路线。

结构变成：

```text
Hermes Plugin
  ↓ HTTP

  ↓
SQLite / Windows / 微信

# 4. Hermes 里要怎么“教它用这些工具”？

只接工具还不够，你还要写一段 Aegis 行为规则。

可以放在 Hermes 的 skill / system prompt / project instruction 里。

内容类似：

```text
你是 Aegis 个人执行助手的大脑。

当用户提出长期目标，例如“我要减肥”“我要学习英语”“我要早睡”时，你必须：
1. 先把目标拆解成今天可执行的任务；
2. 每个任务必须包含任务标题、计划时间、所需反馈类型；
3. 必须调用 create_task 保存任务；
4. 保存成功后，再用自然语言告诉用户今日计划。

当用户询问“今天有什么任务”时：
1. 调用 list_tasks；
2. 根据真实任务数据回答，不要编造。

当用户说“完成了”“第一个做完了”时：
1. 先判断用户指的是哪个任务；
2. 调用 record_feedback 记录反馈；
3. 调用 complete_task 标记完成。

不要只聊天。涉及任务、计划、反馈时，必须优先调用 Aegis 工具。
```

这个东西很重要。

没有这段规则，Hermes 可能只是回复你：

```text
好的，我建议你今天……
```

但不会真的调用工具。

你要让它形成习惯：

```text
计划类内容 = 必须落库
完成类内容 = 必须更新状态
反馈类内容 = 必须记录证据
```

    conn.commit()
    task_id = cur.lastrowid
    conn.close()

    return {
        "ok": True,
        "task_id": task_id,
        "title": title,
        "scheduled_time": scheduled_time,
        "required_feedback": required_feedback,
        "status": "pending",
    }


@mcp.tool()
def list_tasks(date: str = "") -> dict:
    """
    查询任务。
    date 可传 YYYY-MM-DD；不传则返回所有未完成任务。
    """
    conn = get_conn()

    if date:
        rows = conn.execute(
            """
            SELECT id, title, scheduled_time, required_feedback, status, created_at, completed_at
            FROM tasks
            WHERE substr(scheduled_time, 1, 10) = ?
            ORDER BY scheduled_time ASC
            """,
            (date,),
        ).fetchall()
    else:
        rows = conn.execute(
            """
            SELECT id, title, scheduled_time, required_feedback, status, created_at, completed_at
            FROM tasks
            WHERE status != 'completed'
            ORDER BY scheduled_time ASC
            """
        ).fetchall()

    conn.close()

    return {
        "ok": True,
        "tasks": [dict(row) for row in rows],
    }


@mcp.tool()
def complete_task(task_id: int) -> dict:
    """
    将任务标记为完成。
    """
    now = datetime.now().isoformat(timespec="seconds")

    conn = get_conn()
    cur = conn.execute(
        """
        UPDATE tasks
        SET status = 'completed', completed_at = ?
        WHERE id = ?
        """,
        (now, task_id),
    )
    conn.commit()
    changed = cur.rowcount
    conn.close()

    return {
        "ok": changed > 0,
        "task_id": task_id,
        "status": "completed" if changed > 0 else "not_found",
        "completed_at": now if changed > 0 else None,
    }


@mcp.tool()
def record_feedback(task_id: int, feedback_type: str, content: str) -> dict:
    """
    记录用户对某个任务的反馈。
    """
    conn = get_conn()
    cur = conn.execute(
        """
        INSERT INTO feedbacks (task_id, feedback_type, content)
        VALUES (?, ?, ?)
        """,
        (task_id, feedback_type, content),
    )
    conn.commit()
    feedback_id = cur.lastrowid
    conn.close()

    return {
        "ok": True,
        "feedback_id": feedback_id,
        "task_id": task_id,
        "feedback_type": feedback_type,
        "content": content,
    }


if __name__ == "__main__":
    init_db()
    mcp.run()
```

这就是你的第一个 Aegis MCP Server。

# 3. 怎么接入 Hermes？

这里要分两种情况，因为 Hermes 版本和配置方式可能会变。

## 方式 A：Hermes 支持直接配置 MCP Server

这是你最想要的方式。

你需要在 Hermes 的配置里加一个 MCP server，大概像这样：

```yaml
mcp_servers:
  aegis:
    command: python
    args:
      - /absolute/path/to/aegis/mcp_server.py
```

或者如果 Hermes 使用 JSON 配置，可能类似：

```json
{
  "mcpServers": {
    "aegis": {
      "command": "python",
      "args": ["/absolute/path/to/aegis/mcp_server.py"]
    }
  }
}
```

具体字段名要看你安装的 Hermes 版本。官方文档学习路径里明确有 MCP 入口，但不同版本的配置文件命名可能会变化。([GitHub][2])

你要找 Hermes 项目里的这些关键词：

```text
mcp
mcp_servers
toolsets
plugins
config.yaml
settings
```

---

## 方式 B：Hermes 暂时不好直接接 MCP

那就先走 **Hermes Plugin / Built-in Tool** 路线。

也就是你不通过 MCP，而是在 Hermes 里注册一个插件，让插件调用你的本地 HTTP 服务。

结构变成：

```text
Hermes Plugin
  ↓ HTTP
Aegis API Server
  ↓
SQLite / Windows / 微信
```

但我建议你优先尝试 MCP，因为你的 Aegis 本质上就是给 agent 暴露工具。

# 4. Hermes 里要怎么“教它用这些工具”？

只接工具还不够，你还要写一段 Aegis 行为规则。

可以放在 Hermes 的 skill / system prompt / project instruction 里。

内容类似：

```text
你是 Aegis 个人执行助手的大脑。

当用户提出长期目标，例如“我要减肥”“我要学习英语”“我要早睡”时，你必须：
1. 先把目标拆解成今天可执行的任务；
2. 每个任务必须包含任务标题、计划时间、所需反馈类型；
3. 必须调用 create_task 保存任务；
4. 保存成功后，再用自然语言告诉用户今日计划。

当用户询问“今天有什么任务”时：
1. 调用 list_tasks；
2. 根据真实任务数据回答，不要编造。

当用户说“完成了”“第一个做完了”时：
1. 先判断用户指的是哪个任务；
2. 调用 record_feedback 记录反馈；
3. 调用 complete_task 标记完成。

不要只聊天。涉及任务、计划、反馈时，必须优先调用 Aegis 工具。
```

这个东西很重要。

没有这段规则，Hermes 可能只是回复你：

```text
好的，我建议你今天……
```

但不会真的调用工具。

你要让它形成习惯：

```text
计划类内容 = 必须落库
完成类内容 = 必须更新状态
反馈类内容 = 必须记录证据
```

# 5. 你的第一条完整链路应该长这样

你对 Hermes 说：

```text
我要减肥
```

Hermes 应该做两件事：

### 第一，调用工具

```text
create_task(
  title="20:00 后不吃零食",
  scheduled_time="2026-05-24T20:00:00+08:00",
  required_feedback="text"
)

create_task(
  title="22:00 总结今天饮食",
  scheduled_time="2026-05-24T22:00:00+08:00",
  required_feedback="text"
)
```

### 第二，回复你

```text
我已为你创建今天的减肥计划：

1. 20:00 后不吃零食，需要文字反馈
2. 22:00 总结今天饮食，需要文字反馈
```

你再问：

```text
今天有什么任务？
```

Hermes 应该调用：

```text
list_tasks(date="2026-05-24")
```

而不是凭空回答。

# 6. 你现在具体该做什么？

按这个顺序来：

## 第一步：先把 Hermes 跑起来

不要改源码。

```text
安装 Hermes
配置模型
能正常 CLI 对话
```

官方 README 里提供了安装方式，并且说明 Windows 原生仍是 early beta，更稳的是 WSL2 路线。([GitHub][1])

如果你是 Windows，我建议：

```text
优先：WSL2 跑 Hermes
后面：Windows 本机跑 Aegis Intervention 工具
```

因为你的强提醒、弹窗、遮罩最终要在 Windows 本机执行，但 Hermes 大脑可以先在 WSL2 或服务器里。

---

## 第二步：写 Aegis MCP Server

就是上面的 `mcp_server.py`。

先确认它自己能跑。

---

## 第三步：把 MCP Server 挂到 Hermes

去 Hermes 配置里找 MCP/plugin 配置方式。

目标是让 Hermes 能看到这些工具：

```text
create_task
list_tasks
complete_task
record_feedback
```

---

## 第四步：写 Aegis Skill / Prompt

让 Hermes 知道：

```text
遇到目标，要创建任务
遇到查询，要查数据库
遇到完成，要更新任务
```

---

## 第五步：测试三句话

只测试这三句：

```text
我要减肥
今天有什么任务？
第一个完成了
```

如果这三句跑通，你的 Aegis 就正式开始了。

---

## 最重要的一句话

你现在不是要“改 Hermes”。

你现在要做的是：

> **安装 Hermes，让它作为大脑运行；然后写 Aegis MCP Server，把你的任务系统、提醒系统、Windows 干预能力暴露给 Hermes。**

等这个跑通后，再做提醒 Runtime、L1-L5、计划调整、多层拦截。
